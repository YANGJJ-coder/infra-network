# ARCH-20260714-01：建立 Personal Network Infrastructure（`infra-network`）独立仓库

## 原因

将 Personal Network Infrastructure 的脚本、Compose、配置模板、HomeStream Config Generator、测试和文档从临时工作目录纳入独立版本控制，避免与业务仓库混杂。`infra-network` 是该项目保留的 Git 仓库名称。

## 范围

- 建立 `docker/`、`caddy/`、`generator/`、`templates/`、`scripts/`、`tests/` 和 `docs/` 目录边界。
- 配置 Git 忽略规则，禁止密钥、订阅标识、数据库、证书、备份、日志和运行时目录进入版本库。
- 将历史文档中的真实订阅标识改为占位符。
- 不执行任何 SSH、Docker、Caddy、3X-UI、DNS、证书或 VPS 配置变更。

## 风险

脚本源文件目录调整后，直接从仓库执行历史部署脚本可能因旧路径失效而失败。`scripts/bwg-phase7.2-config-generator.sh` 已按新目录结构更新；其余冻结脚本仅作为历史恢复与审计资料，未经新 Phase 不得执行。

## 回滚

仅版本库变更：回退本次 Git 提交并删除远端 `main` 的对应提交。生产服务器没有任何本次部署，因此不存在服务器回滚操作。

## 验证

- `bash -n scripts/*.sh tests/*.sh`
- `PYTHONPATH=. python3 tests/config_generator.test.py`
- `bash tests/*.sh`
- Git 暂存内容安全扫描，确认没有真实订阅 ID、私钥、数据库、`.env`、备份或日志。
